# Site stam.house

Site de STAM, édité par ELIEL : accueil, aide, politique de confidentialité, mentions légales.
Publié avec GitHub Pages (branche `main`, racine), domaine `stam.house` (fichier `CNAME`).

**Référencement désactivé jusqu'à la sortie de l'application** : chaque page contient
`<meta name="robots" content="noindex, nofollow">`. À retirer le jour du lancement,
puis déclarer le site dans Google Search Console.
